# 🫀 AI Cardiovascular Health Predictor Web App

Developed by **DHARSHINI S** for Advanced Placement Showcase.

## 🎯 Project Overview
This is an end-to-end Machine Learning web application that predicts potential cardiovascular health strains based on patient bio-clinical parameters. It leverages a real-world dataset and delivers live interactive diagnostic assessments.

## 🛠️ Tech Stack & Tools Used
- **Language:** Python
- **Data Libraries:** Pandas, NumPy
- **Machine Learning Architecture:** Scikit-Learn (Random Forest Classification)
- **Web UI Framework:** Streamlit Framework
- **Server Deployment:** Localtunnel Cloud Network

## 🧠 Machine Learning Approach
1. **Data Preprocessing:** Handled open-source Kaggle clinical repository columns data mapping attributes.
2. **Feature Allocation:** Processed crucial patient diagnostic metrics variables (`age`, `sex`, `trestbps`, `chol`, `thalach`).
3. **Classification Strategy:** Tuned predictive validation pipeline models to successfully map biological strain probabilities metrics instantly.
